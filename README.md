# Network Traffic Analysis

A practical archive of packet-level network analysis. Understanding how systems communicate is fundamental to securing them. This repository contains my deep dives into various network protocols and traffic captures.

## Objective
To demonstrate proficiency in deep packet inspection, identifying network anomalies, and understanding the raw mechanics of the TCP/IP stack.

## Repository Structure
* **/Malware-Traffic:** Markdown write-ups and analysis of malicious `.pcap` files, detailing payload delivery and command-and-control (C2) communication. *(Note: No live malware is hosted here, only traffic logs and analysis).*
* **/Protocol-Deep-Dives:** Breakdowns of specific protocols (TCP, UDP, ICMP, DNS), handshakes, and flag manipulation based on Wireshark captures.

## Tools Used
* Wireshark / TShark
* Tcpdump
* Zeek
